# S5 Maple 风格三栏布局

## 目标

S5 将阅读器收束为清爽的三栏工作区：文件树、阅读/编辑区、Copilot 区。移除独立顶部工具栏，避免重复占用 Hana 页面高度。

## 布局规则

- 左右栏和中间栏独立滚动，工作区本身不因文件树长度而增高。
- 左右栏可折叠；折叠状态写入本地布局设置。
- 栏间分隔线支持指针拖动调整宽度，宽度写入本地布局设置。
- 中间栏使用较浅的近白背景；左右栏使用轻微暖灰/米色层次。
- 强调色沿用低饱和莫兰迪蓝方向。

## 视觉变量

当前 CSS 以以下变量作为后续换色入口：

- `--reader-bg`
- `--reader-middle-bg`
- `--reader-side-bg`
- `--reader-card`
- `--reader-soft`
- `--reader-border`
- `--reader-text`
- `--reader-muted`
- `--reader-accent`
- `--reader-accent-soft`
- `--reader-shadow`

## 代码阅读

本阶段不引入新的代码编辑器内核。源码编辑继续使用轻量文本编辑框，保留语法可读性、Tab 缩进、自动保存和回撤；后续仅在真实使用痛点明确时再考虑更重的编辑器方案。
