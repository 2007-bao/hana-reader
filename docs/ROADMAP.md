# Hana Reader 后续功能清单

当前版本：`v0.9.0`

本文件只记录尚未完成的产品能力，不规定具体开发顺序。

## 核心功能

### 1. AI Copilot

- 接入 Hana AI 对话能力
- 根据当前文件、选中文本和用户明确提供的上下文提问
- 总结、解释、提取知识点与生成修改建议
- 将 AI 建议应用回 Markdown
- 对话历史、失败重试与上下文长度控制

### 2. Markdown 扩展批注与审阅

- 选中文本后添加批注
- 批注回复、编辑、删除和完成状态
- 黄色高亮
- 下划线与其他审阅标记
- 批注与原文位置绑定
- 重新打开文件后恢复批注
- 批注侧栏与原文定位
- 撤销、冲突检测与安全写回
- 不破坏普通 Markdown 文件的兼容性

### 3. 笔记本增强

当前已支持右侧 Copilot / Notebook 切换与本地自动保存。后续可继续增加：

- 笔记与当前文件、选中文本建立引用关系
- 从批注或 AI 回复一键生成笔记
- Markdown 笔记预览
- 多份笔记与最近笔记管理
- 笔记导出与安全写回

## 配套能力

- 全文搜索与结果定位
- 跨文件问答
- Git 状态查看
- 多标签或最近打开文件
- 更完整的批注筛选和审阅工作流
- 深色模式、键盘操作、可访问性与长文档性能持续优化

## 当前版本边界

`v0.9.0` 的目标是完成阅读工作台的基础形态：

- 三栏阅读布局
- Maple 视觉体系
- Markdown 与常见代码阅读
- 安全编辑、写回、冲突检测、Diff 与撤销
- 代码安全 HTML 预览
- 文件树图标、层级线与滚动位置保持
- 右侧 Notebook 基础记录能力

AI Copilot 的实际接入和 Markdown 扩展批注属于后续核心开发内容。
